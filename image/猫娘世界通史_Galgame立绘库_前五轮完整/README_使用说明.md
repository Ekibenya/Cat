# 《猫娘世界通史》Galgame 立绘与背景库

本包按原插图标题整理为 **41 个场景文件夹**。

## 内容统计

- 透明组合立绘：82 张（每场景猫娘组、人类组各 1 张）
- 透明单角色立绘：194 张（猫娘 119，人类 75）
- 原始纯绿幕组图：82 张，供日后重新抠图或调整边缘
- 第一轮纯背景图：41 张（每个场景 1 张，1536×1024）
- 第二轮纯背景图：41 张（每个场景 1 张，1536×1024；与第一轮为不同地点、机位或时段）

## 每个场景的目录结构

- `组合立绘/`：一张图内放 1–3 个角色，PNG 真透明背景
- `单角色立绘/`：按从左到右顺序拆分的单人 PNG
- `原始绿幕/`：生成时的纯绿色背景原图
- `背景图/第一轮_背景.png`：与本场景对应的无人 Galgame 背景
- `背景图/第二轮_背景.png`：同一时代的另一处无人 Galgame 背景

所有透明立绘均已通过 PNG 解码和 Alpha 通道检查；两轮背景均已通过 PNG 完整解码与尺寸检查。具体角色数量及路径见 `立绘清单.csv`。

后续轮次会继续放入同一场景的 `背景图/`，并命名为 `第三轮_背景.png`、`第四轮_背景.png`，不会覆盖前两轮。

命名说明：`猫娘01.png` / `人类01.png` 等数字表示该组图中从左到右的顺序。
