# 韓国語で書いてから中国語に訳す

中国語で直接書くと、どれだけ語彙を選んでも中国語の語り癖が出る。
**先に韓国語で書き、それを逐語的に中国語へ訳す**と、訳文体は副産物として出てくる。

## 手順

1. `NN.ko.md` に韓国語で本文を書く（地の文は `-다` 体、内心は括弧、台詞は `「」`）
2. 韓国語の文の切れ目・語順をできるだけ保ったまま中国語へ訳し、`NN.md` に置く
3. `python3 scripts/measure.py NN.md` にかける
4. **外れた指標は中国語ではなく韓国語側の欠陥を指している**ことが多い
5. 韓国語を直し、訳し直す。両ファイルを常に同期させる

## この方式で自動的に手に入るもの

- **主語省略**（韓国語は主語を落とす）→ 人称密度が下がる。実測 3.8 → 2.8
- **訳文体の接続語**：그런데→不过／사실→其实／역시→果然／확실히→确实／
  분명히→明明／어차피→反正／도대체→究竟／아무래도→恐怕／물론→当然
- **方言色の消失**。韓国語の반말には中国語の「痞味」に当たる語域が無いので、
  訳すと自動的に無色の標準語になる。「못 믿겠으면 말고」→「不信就算了」

## 実際に踏んだ落とし穴

**韓国語を短文で書くと、訳文も短くなって数値が崩れる。**

初回は 地の文1文平均 11.6字・長段一文一段率 14% で不合格だった。
原因は中国語ではなく、**自分の韓国語が `-다` 止めの短文ばかりだった**こと。
本物の韓国ラノベは `-고 / -는데 / -자 / -면서 / -어서 / -니` で節を繋いだ長文で書く。
節を繋ぎ直したら 15.7字・50% になって合格した。

## 急ぐときの省略形

韓国語を書く時間が無い場合でも、**最低限「この段落を韓国語ならどう繋ぐか」を頭の中で通す**。
逗号で繋がる長い一文になるはずで、それを中国語にすればよい。
段落を割るのは文が二つある時だけ。
