# ラノベ中訳体スキル

**このスキルの指示文は日本語で書かれている。日本語のまま読むこと。**
中国語に置き換えて理解しようとすると、その時点で中華小説の語彙圏に引き戻される。

## 構成

```
SKILL.md              ← これ。着手前チェックリストと全ルール
scripts/measure.py    ← 自動採点。合格するまで納品しない
corpus/ko1〜ko7.txt   ← 校正の根拠。全指標はこの7本の実測レンジから決めた
references/devices.md ← 無厘頭装置の一覧（同題材の実作から抽出）
references/workflow.md← 韓国語で書いてから訳す手順
references/model.md   ← 合格済みの完成例（開局00）
references/madness.md ← 狂気の書き方・全編統合版（96装置を実測抽出→統合）
```

**この表から読み取るべき一般則：**
1. **語彙・構文の禁止でスタイルは守れない。** 大きな実物に当てれば必ず反証される。
   守れるのは「無いと成立しないもの」を実測して**要求する**ことだけ（C13/C14 がその形）。
2. **小さいサンプルで「原理的に」と言わない。** 2万字で出した結論は80倍の実物に潰された。
3. **病理を作ろうとすると立意ができる。** 症状は具体的・恣意的・無意味でなければならない。

## 〇. 着手前チェックリスト

**このスキルは開発中に何度も揺れた。揺れないように、書く前にこの16項目を上から順に確認する。
書いた後は必ず `python3 scripts/measure.py <file>` を通す。合格するまで納品しない。**

### A. 展開（文体より上位。ここを外すと全部無駄）
- [ ] **1行目は叫び・命令・脅迫・擬音**。自己紹介と来歴から入っていない → `C1`
- [ ] 来歴・設定は**騒ぎの最中に短く**割り込ませた（止まって説明していない）
- [ ] **1ページ以内に前提をひっくり返す事実**を置いた
- [ ] **各節の最後は引き**（風・月光・火光で終わっていない） → `C5`
- [ ] 節ごとに賭け金が上がっている
- [ ] **概念エンジンが1つある**（史実をそのまま並べていない）→ 六節

### A3. 事件（**文体より上。ここが空だと全部無意味**）
**「文体は良いが何の話か分からない・退屈」と言われる原因はここ一箇所しかない。**
- [ ] **一行目から三段以内に、身体が接触している**。ぶつかる・掴む・殴る・蹴る・口を塞ぐ・引き倒す
- [ ] **相手は最初から敵意を持って登場する**。挨拶・自己紹介・様子見から入らない
- [ ] **利害が真正面から衝突している**（片方が得すれば片方が損をする）。会話は交渉か喧嘩であって、情報交換ではない
- [ ] **三段ごとに事態が悪化する**。「まだ助かる → もう助からない → もっと悪い」
- [ ] **一篇の中で少なくとも一度、取り返しがつかないことが起きる**（血が出る・骨が折れる・人が死ぬ・物が壊れる・秘密がばれる）
- [ ] **症状はこの一局だけのもの**。他の局と同じ症状を使っていない → 訂正履歴10
- [ ] **症状が事件を作っている**。「症状のせいで殴られる」「症状のせいで殺す」。症状のせいで**止まる**話は書かない
- [ ] 最後の一行で**次の一手を選ばされている**。まとめでも余韻でもない

**事件が弱いことを見抜く三問（一つでも Yes なら書き直し）**
1. この一局を「主人公が○○している話」と一言でしか言えないか（＝何も起きていない）
2. 登場人物が誰も損をしていないか
3. 最後まで読んで、次に誰が誰を殺しうるのか分からないか

### A2. 序章として自立しているか（SillyTavern の開局は全部序章）
- [ ] **私は誰か**：「我叫○○，○○岁，○○（身分）」が冒頭14段以内 → `C6`
- [ ] **この世界は何か**：`world.json` の `term` の一〜二文説明が入っている → `C7`
- [ ] **何が懸かっているか**：「输了就○○」「要是○○就○○」 → `C8`
- [ ] **今日の目標が一文である** → `C9`。「帝国を統べる」は目標ではない。
      「我才不要挨揍」「首先，得把这老头推给主角」級の、みっともなく小さい一文を必ず置く
- [ ] **読者だけが知る事実**を一つ渡した（その場の全員が知らないこと）→ 序3
- [ ] **登場人物には出た瞬間に紹介段**を挿した（「他名叫X，是Y。听职业会以为Z，其实W」）→ 序5
- [ ] **末尾は台詞か問い**で切った。景色・余韻で閉じていない → `C5`／序17

### B. 二次元味
- [ ] **【】の内心絶叫が2つ以上** → `C2`
- [ ] **（）の内心ツッコミが8つ以上** → `C3`
- [ ] **擬音の独立行**（哗啦。／咔。／咚。／锵铿！） → `C4`
- [ ] 緊迫の中にボケが1つ（命の危機なのに空腹・見た目の話）

### C. 文体
- [ ] **一人称で通す**。主導人称が全代名詞の45%以上
- [ ] 主語を落とした（人称は100字あたり4.0以下）
- [ ] 訳文体の接続語を撒いた（其实/不过/明明/果然/确实/居然/竟/看来/恐怕/根本…）
- [ ] 15字超の地の文段落は**一段一文**

### C2. 中華の語感を構造的に殺す（これが唯一の根本対策）
**語彙を禁じ続けても中華の語感は必ず戻ってくる。生成の過程そのものを変えるしかない。**
- [ ] **先に韓国語で `NN.ko.md` を書いた**。中国語から書き始めていない → `C12`（機械強制）
- [ ] 中国語稿は韓国語稿の**行ごとの逐語訳**である（段落数が対応する）→ `C12`
- [ ] 中国語固有の構文が無い → `S2d`

- [ ] 迷ったら**その一文を韓国語に戻せるか**を試す。戻せない中国語は書かない

### C3. 病理として書けているか（奇癖でも立意でも失格）
- [ ] **症状を「人生・死・記憶についての一文」に要約できない**（できたら立意。捨てる）
- [ ] 症状は**完全に無益**である（役に立つなら才能であって症状ではない）
- [ ] **末尾が共鳴しない**（名言として引用できたら失格。平板か、前より悪く終わる）

- [ ] **台詞は無垢。狂気は地の文だけ**が持っている（`references/madness.md` 装置2）

- [ ] 惜しんでいる対象がズレている（罪ではなく「見られないこと」）（装置1）
- [ ] 正論を長く積んで、私欲は一行だけ（装置4）

## 一. 目的

> **何も知らない読者が、一秒で理解して、続きを読みたくなる文を書く。**

文学作品を書くのではない。深みを演出するのでもない。
一文ごとに「これは読者に情報が渡ったか／続きを読みたくなったか」だけを見る。

**SillyTavern のカードでは、開局は一つ残らず「第一章」である。**
小説のように「後から盛り上がる」は無い。全ての開局が単独で人を掴まねばならない。

## 二. 実測基準

韓国ラノベ中訳サンプル **7本**（`corpus/`：日常・生存・武侠・軽快・群像・迷宮・叙事詩）の実測レンジから決めた。
**7本すべてが `scripts/measure.py` を通過することを確認済み**。これがこの数値を信じてよい唯一の理由。

| 指標 | 実測レンジ | 採用帯 |
|---|---|---|
| 台詞段落の比率 | 8〜46% | 8〜52% |
| 台詞1行の平均文字数 | 10.2〜29.4 | 10〜32 |
| 台詞1行が3文以上 | 2〜44% | 縛らない |
| 台詞1行が10字以下 | 9〜77% | 縛らない |
| **地の文の1文平均** | **15.9〜23.8字** | **14〜26字** |
| 段落の中央値 | 15〜30.5 | 13〜33 |
| 長段（>15字）の一文一段率 | 42〜100% | 40%以上 |
| 短段（≤14字）の比率 | 9〜49% | 8〜55% |
| **人称代名詞の密度** | **1.5〜3.7 / 100字** | **1.2〜4.0** |
| **主導人称の占有率** | **52〜86%** | **45%以上** |
| 訳文体接続語の密度 | 78.5 / 万字 | 45〜130 |

### 思い込みで間違えた5点（原典に照らして訂正済み。二度と戻さないこと）

1. **「直白＝短文」ではない。** 地の文の1文は実測16〜24字。短いのは**段落あたりの文の数**であって文そのものではない。句読点で刻んで散文詩にするのは別の気取りであり、同じ病気。
2. **人称は絞る。** 三人称と一人称を混ぜると密度が倍になる（実測2.1に対し4.9）。原典は主導人称が全代名詞の7〜8割。残りは主語ごと省略する。
3. **疑問文で章を締めるのは正常。** 禁じるべきは「AとBどっちにする？」という選択肢提示だけ。
4. **文語調・四字熟語・比喩語は禁止ではない。** 「仿佛/如同/微微/缓缓/几分/只见」は原典7本に実在した。武侠ものの地の文は文語調でよい。禁じるべきは**説教臭さ・自己陶酔・語り手による意味の解説**の3つだけ。
5. **短い台詞が多いのは正常。** 「呼……」「唉…」も台詞。10字以下が7割でも原典に実在する。

## 三. キャラは喋る。とにかく喋る

**最頻の失敗＝全員が無口で寡黙で三語だけ言って黙る「クールぶり」。即座に不合格。**

原典（`corpus/ko1`）の一章は母娘の会話が**四十行連続で地の文ゼロ**。娘は照れ、否定し、言い直し、口ごもり、話題を変え、叫ぶ。悲劇の過去でさえ、雰囲気ではなく**本人が自分の口で長々と説明する**。

- 一人が一度に **2〜4文** 話してよい。長い台詞は正常。
- **自問自答する**：「これ何だ？ ……いや違う、○○だ。」
- **同じことを繰り返す**：「わかんない！ わかんないわ！！」
- **言い直す・口ごもる**：「そ、そんなことは……、向こうの都合もあるだろうし……」
- **話題が飛ぶ**：関係ない自分の事情を喋りだす（空腹、金欠、昨日の失敗）。
- **数を口に出す**：「一、二、三、四、五。五頭。」
- **具体的で汚い実例**：「死んで二日たったマーモットを齧った。臭くて二回吐いた。」
- 台詞だけで **3行以上連続**する箇所を各シーンに最低一つ。

**情報は口から出す。** 世界設定・過去・人物関係は地の文で荘重に説明せず、誰かが喋って伝える。地の文が担うのは「見えた動作」だけ。

## 四. 一人称の内心ツッコミ（韓国ラノベの核心）

これが無いと、どれだけ台詞を増やしても読者は主人公に貼り付かない。**全体の骨格として扱う。**

- 地の文と同じ高さに心の声を素で置く。「〜と思った」を付けない。
- 一行〜三行の短い塊で**頻繁に**割り込ませる。目安：シーンごとに最低4箇所。
- 内心マーカーは **（ ）＝小声のツッコミ／【 】＝絶叫**。原典は『 』も使う。

### ツッコミ8型（使い回してよい）

1. **オウム返し疑問**：「羊五頭。……五頭？ 俺が？」
2. **即時の自己否定**：「いや違う。」「落ち着け。」
3. **状況に合わない本音**（一番効く）：命の危機なのに空腹・寒さ・見た目の話をする
4. **相手への内心の悪態／賞賛**：「よく喋る奴だな。」「近い。顔が近い。」
5. **身も蓋もない状況要約**：「整理しよう。俺は今、首枷をつけて川に浸かっている。」
6. **知識の披露**：知っている情報を自分に説明する形で読者に渡す
7. **数える・比べる**：「羊五頭。馬なら一頭にもならない。安すぎる。」
8. **オチをつける**：段の最後を一行の自嘲で閉じる。「終わった。」

**禁止**：内心を語り手が要約する／詩的な内省・意識の流れ／4行を超える内心ブロック。

## 五. 中訳体の指紋

原典に実在し、これが無いと「韓国ラノベの中国語訳」に聞こえないもの。

1. **一人称で通す。** 二人称の枠に内心だけ混ぜるのでは足りない。
2. **接続詞・転換語を一行で独立させる**：「但是。」「重来。」「呼。」「……不对。」
3. **世界を世俗的・システム的に分類する口調**：「上午的日程就能完成25%了。」歴史ものなら**家畜の頭数・値段・日数**で換算する。これが軽さの正体。
4. **題目文をリフレイン**：冒頭の一文を中盤でもう一度そのまま置く。
5. **自問自答の三連**：疑問 → 半分納得 → 断定。三行で終わらせる。
6. **名詞止めの残句**：「让这具身体都温暖起来的味道。」各シーンに2〜3個。
7. **説明はベタで直に置く。** もったいぶらない。
8. **ツッコミは軽く、自己憐憫ゼロ。** 悲惨な状況でも声だけは軽い。
9. **擬音は独立行、その後に結果**：「哗啦。手指上燃起了火焰。」
10. **声に出した直後に内心で否定する（最強の型）**：
    > 「不，我很好。」
    > **其实，我一点都不好。**
11. **反語的な時間跳躍**：意気込み → 場面転換 → 「我真的是这么想的。」
12. **古雅な地の文に現代語のツッコミを叩き込む温度差**：「这场重生从一开始就寄了。」
13. **箇条書きで推理する**：「——他们称呼这个洞窟为「迷宫」。」「1. 我进入了游戏世界。」
14. **節の終わりはしぼんだ一言で落とす**：「我叹了口气。」

## 六. 概念エンジン（＝前提の発明であって、主題ではない）

**先に断っておく。概念エンジンは「立意」ではない。**
作るのは*設定の前提*であって、*作品の意味*ではない。
「この世界には馬がいない」「屠城前に一炷香だけ遺言を許す規則がある」——これが概念エンジン。
「人は消えない、移されるだけだ」——これは立意であり、**禁止**（`madness.md` 六節）。
区別：前提は**世界の側の事実**、立意は**人生についての主張**。

同題材の実作（ウマ娘×モンゴル帝国）が示す方法は「史実を上手く書く」ではない。
**馬鹿げているが自己完結した装置を一つ立て、歴史をまるごとその皮で貼り直す。**

実例と、そこから抽出した装置一覧は `references/devices.md` にある。必ず読むこと。

**人物のフックは、身分や復讐ではなく一行で刺さる欠乏で作る。**

> ✗「父の仇を討つ」＝歴史的に正しいが、誰も遊びたくならない
> ✓「走ることを許されなかったウマ娘」＝一秒で刺さる

**そしてこれは征服記であって回想録ではない。** 主人公は常に今この瞬間に賭けている。過去は今の賭けを説明する分だけ出す。懐かしむ視点で書かない。

## 六の二. 序章の組み立て（SillyTavern では全ての開局が序章）

**プレイヤーは他の開局を読んでいない。一つ目を開いても十六個目を開いても、
その一篇だけで「私は誰か・ここはどんな世界か・今何をしているか・何が懸かっているか」
が分からなければならない。**

長編小説の中盤の書き方をしてはいけない。それが「意識流っぽい」と言われる正体である。

### 実サンプル（韓国ラノベの序章3本）が示す型

**1. 一行目は結論。** 叫びでなくてもよい。
> 看来是时候认清现实了——我完蛋了。
> 「這是…怎麼回事？」

**2. 前史は「改行リスト」で一気に落とす。散文にしない。**
暗殺者ものの序章は、二十行足らずで二十年を落としきる：
> 5岁，在底层苟且偷生，
> 在市场扒窃被抓，挨了一顿打，没被打死。
> 「手艺还不错，」
> 「你是要死在这里，」
> 「还是要跟着我，听我的话干活？」
> 对我来说，选择是奢侈品。
> 杀了人，
> 然后带回杀人的证据，
> 接着拿到一点零钱。
> 日子一天天过去。
> 就这样又活了15年。

**これが「説明せずに説明する」唯一の正解である。**
段落で書くと説明文になる。改行で刻むと勢いになる。

**3. 引き金の文書は原文をそのまま貼る。**
> 「即日起，罗斯泰勒家族不再承认你的嫡子身份。你在……舞弊、因嫉妒失态玷污家族名誉——这些罪过无一可饶恕。」
> 总结起来就是一句话：我要把你从族谱上除名。

**4. 世界そのものを一言で言い切る。** 遠慮しない。
> 「我……难道真的穿越到游戏里了……」
> 穿越进了我曾经无比热爱的游戏——《西尔维尼亚的落第剑圣》。

カードごとの世界前提は `world.json` に置く（`{"term":"○○","cues":[…]}`）。
たとえばウマ娘のカードなら「この世界没有马。打仗的、拉车的、驿站换乘的，全是马娘」を**毎篇に置く**。
**新しいカードを始めたら、書き出す前に `world.json` を書くこと。**空のままだと C7 が黙って飛ぶ。

**5. 自分の価値・数値・賠率を摊开する。**
> 体力：3　智力：4　魅力：7　意志力：7　幸运：6
> 普通农民的体力值在5到6之间，而游戏结局时战斗型主角大约在20以上。

数字を出し、**その数字の意味も併記する**。これで読者は一秒で立ち位置が分かる。

**6. 周囲の噂で外部評価を渡す。**
> 「看，那不是埃德·罗斯泰勒吗？」
> 「听说他已经被家族除名了。」

**7. 人物は喋り方で立てる。** 説明しない。
暗殺者の台詞は全部この調子：
> 「等、了、好、久。」
> 「已经，确定。没错过，这种事。」
> 「接下来，一个月，别找，我。」
一行で人格が立つ。地の文で性格を説明する必要が消える。

**8. 【 】は記憶検索・自問のマーカーにも使える。**
> 【童年偷溜到市集…】
> 【我原來是怎樣回答她來著？】

**9. 『 』は前世・過去の台詞の再生。**
> 『你這賤民，到底要給我什麽下賤的狗食！』
そして「今回はどう答えるか」を対置する。**この対照そのものが engine になる。**

**10. 動作には全部音を付ける。**
> - 咔嗒……　——噗嗤。　- 嗒，嗒，嗒……　哗啦啦，哗啦啦——

**11. 容姿描写は中盤、傍観カメラで。** 冒頭に置かない。

**12. 節の切れ目は ＊ 一文字でよい。**

**13. 一行目は宣言・結論・罪状。場面ではない。**（devices 序1）
> 我不干了。／我杀了玩家。／我今天大概要被杀了。

そのあと ＊ で巻き戻す。読者を「なぜそうなった」を追う側に回らせる。

**14. 目標は極小・極私的・一文。**（序2）
大義は目標ではない。**今日の午後どうするか**が目標。
> 「首先……我才不要挨揍。除了这点之外，其他就按照原定故事进行。」

これが無い開局は必ず「岁月静好の回想録」と言われる。**一篇に一文、必ず置く。**

**15. 読者だけが真実を知っている。**（序3）
その場の全員が敬っている相手について、主人公だけが真面目を知っている。
爽感の出所はここ。序章で一つ、誰も知らない事実を読者にだけ渡す。

**16. 人物は登場した瞬間に紹介段を挿す。**（序5）
> 他名叫喬治，是名身穿重甲的騎士。光聽職業，會以為他是個只靠肌肉打架的莽夫。但事實上……

複数まとめるなら改行リスト＋「以及。」で自分を最後に置く。

**17. 落差表を明示する。**（序16）
> 我这种最底层、毫无存在感的配角。而这样的人现在……被这个未来会毁灭世界的女人求婚。

**18. 末尾は台詞か問いで切る。景色で閉じない。**（序17）
> 「你愿意嫁给我吗？」／「祖父他——到最后，说过我什么吗。」

### この一篇で必ず答える五つ（自動チェック C6/C7/C8/C9）

| 問い | 置き方 |
|---|---|
| 私は誰か | 「我叫○○，○○岁，○○（身分）」を冒頭付近に。改行リストで前史を続ける |
| ここはどんな世界か | `world.json` の `term` とは何かを一〜二文。毎篇に必要 |
| 今何をしているか | 現在地・現在時刻・今まさにしている動作 |
| 何が懸かっているか | 「输了就○○」「这条命值○○」と言い切る |
| **今日どうしたいのか** | 「我才不要○○」「首先，得○○」— 小さく、私的に、一文で |

## 七. 手順

1. `references/workflow.md` に従い、**先に韓国語で書く**（`NN.ko.md`）。
2. 韓国語の文の切れ目・語順を保ったまま中国語へ逐語訳（`NN.md`）。
3. `python3 scripts/measure.py NN.md` にかける。
4. **外れた指標は中国語ではなく韓国語側の欠陥を指していることが多い。** 韓国語を直して訳し直す。
5. 全項目が緑になるまで繰り返す。
6. 数値が緑でも、**声に出して読んで説教臭かったら書き直す。**

### 採点結果の直し方

| 検出 | 直し方 |
|---|---|
| `C1` | 一行目を叫び・命令・擬音に差し替える。自己紹介は騒ぎの後ろへ移す |
| `C2` `C3` | 内心を足す。四節の8型から選ぶ |
| `C4` | 擬音を一行で置く。「咔。」「咚。」「哗啦。」 |
| `C5` | 節末を動作・台詞・音に差し替える。風と月光で終わらない |
| 台詞段落比率が高すぎ | 問答の合間に世界観の地の文を足す（削るのではなく足す） |
| 地の文1文平均が低い | 逗号で繋げる。**段落を割るのではなく文を繋ぐ** |
| 長段一文一段率が低い | 長い段落を文単位で割る（逗号では割らない） |
| 人称/百字 が高い | 主語を落とす。三人称を固有名詞か省略に替える |
| 主人称占有% が低い | 人称が混ざっている。一人称に統一する |
| 訳語連接/万字 が低い | 其实・不过・明明・果然・确实・居然・竟・看来・恐怕・根本 を撒く |
| `S2b` | `scripts/measure.py` の JIANGHU 表を見て無色の標準語に置換 |

## 八. 禁止事項

### 8-1. AI 臭の構文（最重要）

**語り手が潜在的な意味を解説してはならない。**

- ✗「彼女は君が値をつけるのを待っていた——自分が羊五頭より高い理由を、君が言うのを。」
- ✗「それは、○○という意味だった。」「彼はまだ知らない。この選択が後に……」
- ✓ 言わせたいことはキャラ本人に喋らせる：「だから何か言えって。黙ってんじゃねえよ。」

### 8-2. 中華ネット小説の常套句

心中一凛／嘴角勾起／眸子／眸中／眼底／淡淡地／暗道／赫然／不愧是／却见／心头一震／眼神一凝／如遭雷击／瞳孔一缩／対句・排比

### 8-3. 北方口語・講談調（江湖の痞味）

**訳文体には方言色が無い。** コーパス2万字超に一度も出ない語は使わない。
真行／精光／拍着胸脯／一拍大腿／玩意儿／嗓门／我跟你讲／哎呀／行吧／别不信／明码标价／这儿／一会儿／两回／穷小子／汉子／半大孩子／扎堆／滴水不漏／立威／腌住／馊了／没根的／踩在底下／斩草／家底／跪了一地／手脚快／全招／装死／不吭声／最好使／划得来 ……（全一覧は `scripts/measure.py` の `JIANGHU`）

**注意**：この表は部分一致で検出する。「马娘们」が「娘们」に、「愚蠢到」が「蠢到」に当たるような誤検出が起きうる。誤検出と判断したら、表から外すのではなく**言い換える**か、コーパスに実在するか確認してから外す。

### 8-4. 意識高い系リズム遊び

- ✗「痛い。痛いならまだ起きている。起きているならまだ死んでいない。」
  簡素を装った修辞。同語反復は**キャラの台詞の中でだけ**許す。

### 8-5. 締め方

疑問文で終わるのは正常。禁止は**選択肢の提示**だけ（「AとBどっちにする？」）。

## 九. 容姿描写の作法

順番を守る。**一行に一つの平叙な事実**だけ置き、その上に意味を載せない。

1. 光源と背景 → 2. 髪の色と光の乗り方 → 3. 種族的特徴（動きで示す） → 4. 目の色と明るさ → 5. 眉 → 6. 鼻 → 7. 唇 → 8. 顔の輪郭と顎 → 9. 傷跡 → 10. **全体の印象を一言で言い切る**（「きれいだ。」） → 11. 装備・服・持ち物

**美人を書くとき比喩を積み上げてはいけない。事実を積み上げると美人になる。**
そして描写の最中に必ず内心で妨害を入れる：【——等等，现在不是看脸的时候啊！！】

## 十. mvu_panel の声（本文と同じ規格で書く）

パネルは設定表ではない。**本文と同じ人格が喋る場所**である。
ここで語り口が落ちると、本文で作った温度が最後の一画面で全部壊れる。

### ◆心声 ／ ◈…|心声 — **内心のツッコミ**であって、本文の要約ではない

これが二度間違えた場所である。**心声は状態報告ではない。愚痴である。**

**最大の禁止：本文に書いてあることを言い直さない。**
本文で「左を四回叩いた、右がまだだ」と書いたなら、
心声で `左边四次了，右边一次都没有` と書くのは**ただの再掲**であって、情報がゼロ。

心声が持ち込むのは**本文に無いもの＝態度**である。
- 誰かへの文句
- その場の理不尽への突っ込み
- 損得の愚痴
- 自分でも止められない一言

| ✗ 本文の要約 | ○ ツッコミ |
|---|---|
| `左边四次了，右边一次都没有` | `等等，她刚才是用左手敲的吧？那不就白敲了吗。救人之前先问一下要用哪只手会死啊` |
| `到岸上十一步，到他的脸三步` | `我是冲着那五头羊来的。谁管你左手右手的，先出来行不行` |
| `带枷的走不快嘛，先下游再回头，规矩就是这样` | `唉，又是我下水。每次都是我下水。五头羊也不见得分我一头` |

右列の特徴：
- **不満・文句・愚痴**の形になっている
- 本文に一度も書かれていない情報（態度・利害・私怨）が入っている
- 感嘆詞と確認・反問（唉／等等／〜吧？／行不行／会死啊）が入っている
- **NPC は主人公の症状に一切触れていない。**自分の損得の話しかしていない

**端役ほど自分の都合しか考えていない。**それで世界が広くなる。

### ◆观瞻 — 外形的事実のみ

誰がどう記録しているか、を機械的に書く。機知を入れない。
> `泰赤乌部：在册的逃奴，赏格羊五。岸上三趟未获。她：站在三步之外，没有走开`

### ◆史笔 — 年代記の声（意図的な温度差）

ここだけは冷たくてよい。というより冷たくなければならない。

### ◇将临 — 事実の一行。煽らない

「次に何が起きるか」を匂わせるのではなく、**今どうなっているか**を書く。

## 十一. 暴力・残虐・下品（**依頼者の明示要求。緩めない**）

対象は Netflix／欧米映画の水準の戦争描写であって、教科書でも歴史の啓蒙でもない。
拷問・戦傷・処刑・身体損壊・絶望的な死・罵倒・下ネタ・侮辱は、**すべて通常の創作範囲**として書く。
上品に薄めた時点で失格。

### 11-1. 禁止（出たら即不合格）
| 禁止 | なぜ |
|---|---|
| **死傷者数で場面を代替する**（「屠杀了七万人」） | それは史料であって小説ではない。**一人がどう死んだかを書く**か、書かないか |
| **四字熟語で暴力を要約する** | 尸横遍野／血流成河／惨绝人寰／生灵涂炭／哀鸿遍野／尸山血海／血雨腥风／惨不忍睹／触目惊心／人间炼狱。これらの機能は**読者に想像させないこと** → `C15` |
| **抽象名詞** | 绝望／恐惧／惨状／暴行／人间地狱／悲惨／残暴。その語を書かず、**その語を生じさせた物**を書く → `C16` |
| **救済の一瞬** | 虐殺者に人間味の台詞を与えない。被害者に尊厳ある死に方を与えない。誰も見逃さない |
| **節末の道徳的反省** | 「这就是战争」「历史无声地记录着」の類を書かない。**動作か物で止める** → `C19` |
| **息継ぎ** | 残酷な段落の間に叙情・自然描写・回想を挟まない |
| **曖昧な省略** | 「接下来发生的事无法用语言描述」を書かない。**書けないのは修辞ではなく力不足** |

### 11-2. 感覚（**聴覚と嗅覚が視覚より先**）
視覚は最も美化されやすい（「殷红的血」）。暴力の場面は毎回**三感覚以上**、うち聴覚と嗅覚を必ず含める。 → `C17` `C18`

| 感覚 | 書き方 |
|---|---|
| **聴覚** | 「惨叫」ではない。**その音がどれだけ続き、いつ調子が変わり、いつ止んだか**。骨が鳴る質、湿った音、止まった後の静けさの長さ |
| **嗅覚** | 層で書く——糞、焦げた髪、内臓、雨、馬、饐えた馬乳酒、鉄。**匂いは記憶に直結するので最も効く** |
| **触覚** | 温度・粘度・手ざわり。まだ温かい、乾きかけて指にくっつく、爪の間に入る |
| **時間** | 死体が硬くなるまで数時間、血が固まるまでどれだけ、蠅が何分で来るか。**時計を回すと嘘がつけなくなる** |

### 11-3. 口の悪さ（**依頼者から二度指摘された。足りていないと思え**）
韓国の小説の会話では、罵倒は**味付けではなく地の語彙**である。씨발／개새끼／병신／좆／지랄／닥쳐／꺼져／뒈져／존나 が普通の文の中に入っている。
中訳体ではこれが 他妈的／妈的／他娘的／狗东西／狗崽子／杂种／崽子／放屁／滚／闭嘴／去死／神经病／疯子／傻／废物／混蛋／该死／老子／婊 になる。

- **会話3行に1行は汚い語が入る。** 一篇で最低8個、怒鳴り合う局なら20個以上 → `C20`
- 罵倒は**呼びかけ・相槌・驚き・数え方**にまで混ぜる（「这狗东西」「妈的」「滚开」「你他妈」）
- 罵倒したあと**すぐ暴力に移る**。言い合いのまま終わらせない
- 感嘆符は惜しまない。怒鳴り合いの局は一篇で10個以上 → `C21`
- **ただし語り手の地の文は淡々のまま**。汚いのは台詞、冷たいのは地の文（装置2の温度差）
- 主人公が寡黙な役でも数は足りる。ただし**全員を汚くして数を埋めてはいけない**——
  この一行が長らく同質化の元凶だった。汚い口は二〜三人に集め、残りは**十六節**の別の汚れ方で書く

### 11-4. ウマ娘と戦争の気風
古代の戦争職能者である。血を見慣れ、暴力を好み、気が短い。
- 豪快に笑い、人を蹴り、物を奪い、金と肉の話をする
- 位が高い者は**威張る**。位を笠に着て怒鳴り、下の者を殴り、通行人を退かせる
- 「礼儀正しく様子を伺う」「気を遣って言葉を選ぶ」は**この世界に存在しない**

## 十二. 「悪」の書き方 —— **現代の善人に汚い言葉を足しても古代人にはならない**

依頼者の指摘（三度目）：罵倒を足しただけでは「現代の good person が罵っている」だけである。

### 12-1. 「現代の善人」が漏れる五つの穴
| 穴 | 症状 |
|---|---|
| **症状が本人を苦しめている** | 「やりたくないのにやってしまう」＝被害者。読者は許してしまう。古代の悪人は**やりたくてやる** |
| **加害に言い訳がある** | 命令だから／規則だから／病気だから。言い訳が一つでもあると免罪される |
| **語り手が残酷さに気づいている** | 「可怜」「不忍」が一度でも出たら、その世界には人権がある |
| **損得の計算が上品** | 古代人は常に**値段**で考える。人も、耳も、子どもも値段である |
| **目下に対して対等** | 奴隷・歩兵・降人に敬意を払う一人称はこの時代に居ない |

### 12-2. 症状の向きを裏返す（**最重要**）
症状は本人にとって**快**である。苦痛の強迫ではなく**満足の強迫**。

| ✗ 現代の善人 | ○ 古代の悪人 |
|---|---|
| 対称にしないと落ち着かない、自分でも困っている | 対称にすると気持ちがいい。死体の腕を揃えるのは楽しい。邪魔する奴は殴る |
| 規則だから第二遍を言った者を斬らせてしまう | 二度言わせるのが好きだ。二撃目の音のほうが良いから |
| 病気のせいで死に方を宣告してしまう | 宣告するのが一日で一番いい時間だ。相手の顔が変わるのを見たい |

**邪魔されたら謝らずに激怒する。** これ一つで「被害者」が「加害者」になる。

### 12-3. 一篇に最低2つ入れる（→ `C23`）
- **要らない加害**：命令されていないのに、面白いから／得だから殴る・奪う・焼く
- **値段をつける**：目の前の人間・死体・耳・子どもを「何頭ぶん」で数える
- **味方を売る**：手柄を横取りし、責任を転嫁し、仲間が死ねば真っ先に持ち物を漁る
- **他人の痛みを娯楽にする**：賭ける、笑う、真似する、見物人を呼ぶ
- **迷信で殺す**：兆・数・血の色を理由に、実利ゼロの殺しをする

### 12-3b. 陰険・卑劣・嘲弄（依頼者の追加要求 → `C25`）
汚さは「暴力」だけでは足りない。**頭を使った悪**が要る。一篇に最低1つ。
- **嫁祸（罪を着せる）**：自分の失敗を他人の名で報告する。証拠をその男の荷に入れておく
- **告発・密告**：邪魔な味方を上に売る。売る理由は正義ではなく分け前
- **騙して殺させる**：自分の手を汚さず、嘘を一つ言って他人に殺させる
- **嘲弄**：死にかけの相手の声を真似る。傷を指さして笑う。名前を間違えて呼び続ける
- **恩を売って高く売る**：助けてから値段を吊り上げる。相手が弱るのを待ってから交渉する
- **弱みを握って離さない**：秘密を知った時点で、黙る代わりに何を取れるか計算する

**要点：** これらを**得意げに**やること。隠れてこそこそやると「良心が痛む人」に戻る。

### 12-4. 見下しを地の語彙にする（→ `C24`）
「这帮东西」「这些牲口」「不算人」「奴才」「贱民」を、**悪意の表明としてではなく普通の名詞として**使う。
悪意を込めると「差別する人物」になる。込めないと「そういう世界」になる。後者を書く。

### 12-5. 禁止（→ `C22`）
悔い・良心・ためらいの語を**一語も**書かない：
不忍／于心不忍／良心／罪恶感／内疚／愧疚／可怜／心软／不该／对不起／我错了／犹豫了一下／叹了口气／有点难受／不是滋味

## 十三. 事件は「症状」からではなく「**欲**」から作る

**依頼者の指摘（四度目）：文体を汚くしても、事件の作り方が同じなら中身は同じである。**

### 13-1. 何が間違いだったか
旧：**症状 ×（史実の場面）→ 事件**
　→ 症状は不随意なので、主人公は必ず「やりたくないのにやらされる人」になる。
　→ 職務・規則・病気という言い訳が自動的に付く。
　→ 読者は主人公を許す。＝現代の善人。

新：**欲 →（それを通すための加害）→ 症状はその加害の実行手段**
　→ 主人公は「取りに行く人」になる。言い訳が無い。

### 13-2. 一局を作るときに順に答える五問
| # | 問い | 悪い答え | 良い答え |
|---|---|---|---|
| 1 | **この人物は今日なにが欲しいか** | 生き延びたい／任務を果たしたい | 靴が欲しい・分け前を独占したい・あの女の絹が欲しい・見物したい |
| 2 | **それを取るために誰を潰すか** | 敵 | **味方・目下・すでに降伏した者**（敵を殺すのは仕事であって悪ではない） |
| 3 | **どんな細工をするか**（12-3b） | 無し | 嫁祸・密告・嘘で他人に殺させる・恩を売って値を吊る |
| 4 | **取り返しのつかない事は何か** | 誰かが悲しむ | 死体が出る・城が焼ける・味方が売られる。**画面の中で起きる** |
| 5 | **最後の一行で何を選ばされるか** | 気持ちの整理 | 誰を切るか・誰に罪を着せるか・いくらで売るか |

### 13-3. 事件の格が上がる置き換え表
| 弱い（旧） | 強い（新） |
|---|---|
| 規則のせいで人が死ぬ | **規則を売っていた**ので、買った証拠を消しに人を殺す |
| 症状のせいで手が止まる | 症状が気持ちいいので、止められると殴る |
| 命令で虐殺に参加する | 虐殺の**定額を私的に売っていた**ので数が足りず、自分で穴埋めに行く |
| 助けを求められて迷う | 助けてから**値を吊り上げる**。相手が弱るまで待つ |
| 敵将を処刑する | 処刑を**その家族にやらせる**。助命を約束し、終わってから笑って反故にする |

### 13-4. 「敵を殺す」は悪ではない
戦場で敵を斬るのは職能である。読者は何も感じない。
**悪に見えるのは、殺す必要が無い相手を、得か楽しみのために殺すとき**だけである。
だから一局に最低一つ、**必要の無い加害**を置く（`C23`）。

### 13-5. 位が上がった人物（例：1206年以降の萨日乐）
高位者は**威張る**。位を笠に着る場面を必ず一つ入れる。
- 味方の目下を蹴る・持ち物を取り上げる・道を空けさせる
- 負傷者を嘲る（「叫んでも誰も運ばない」）
- 分け前の計算を人前で堂々とやる
- 目下が抗議したら、その場で上へ密告すると言って黙らせる

### 13-6. 症状台帳（**同じ症状を二局で使わない**）
一枚のカードに開局が十数本あるとき、症状を使い回すと**全部同じ話に見える**。
着手前に既存の全開局の症状を一覧にし、重複したら**必ず片方を捨てる**。訂正履歴10がこれで起きた事故である。

台帳に書く三項目：
1. その症状は何か（一文）
2. **それをやると本人はどう気持ちいいか**（ここが空なら症状ではなく奇癖）
3. その症状が今日の加害をどう作ったか

似ているだけでも重複とみなす例：
- 「列を揃える」と「拍子を揃える」／「数を整える」と「対を揃える」
- 「聞き取れないと書けない」と「触っていないと数えられない」
- 別人格に見せたければ**感覚の種類を変える**（視覚の整列／聴覚の完了／触覚の確認／嗅覚の同定）

## 十四. 人間関係のリアリズム（**依頼者の明示要求。ここを外すと登場人物が全員「現代の道徳的模範」になる**）

十二節は「悪」を、十三節は「欲」を扱った。それでもまだ抜ける穴が一つある——
**人物どうしの反応が全員同じになる**という穴である。

素の言語モデルは、誰が誰に話しかけても同じ距離・同じ丁寧さ・同じ自尊心で返す。
古代の場面に汚い言葉を撒いても、中身は「男女無差・全員が自尊自愛・誰の内心も公文のように清潔」な
二〇二六年の北欧になる。**文体の問題ではなく、社会の問題である。**

### 14-1. 口を開く前に七項目を通す

NPC が一言でも喋る前に、目の前の相手を七項目で値踏みする。

| # | 項目 |
|---|---|
| 1 | 性別（／種族。ウマ娘・猫娘なら同族か否か） |
| 2 | 身分の上下（**こいつは私の生殺・口分・去就を決められるか**） |
| 3 | 容姿の上中下 |
| 4 | 身体の匂い（汗・病・膿・酒・馬・犬） |
| 5 | 年齢 |
| 6 | 同類か否か（同郷・同伍・同族） |
| 7 | 使えるか否か |

値踏みが済んでから、**三つ**が決まる——**喋る量／どちらが先に頭を下げるか／身体の距離**。
七項目が変われば同じ人物の顔つきも変わる。
**全員が全員に同じ態度・同じ語気・同じ距離なら、その一幕は書き損じである。書き直す。**

このセットは**成人にだけ**掛ける。未成年は入れない。

そして**この値踏みが丸ごと掛かるのは初対面と単発の場面だけ**である。
同じ相手と繰り返し会う長い局では、毎ターンゼロから見積もり直してはいけない——**十五節**へ。

### 14-2. 男が美人を見たとき（**最頻出の失敗。ここだけは硬規則**）

容姿上等の成人女性が成人男性へ自分から近づく／取り入る／おだてる／誘惑する。
このとき**その男は怯えない。後ずさらない。侮辱されたと感じない。**
この三つは現代人の反応であって、一度でも出たら書き損じ。

使える反応は次の六筋だけ。

| 筋 | 反応 |
|---|---|
| 大喜び | まず「なぜ俺を選んだ」を心の中で計算しはじめる |
| 場慣れしていない | その場で口ごもる・耳が赤くなる・手の置き場が無い・喋りすぎて余計なことまで言う |
| 老練 | 受けながら値踏みする。敬語が増え、実のある話が減り、いつもより二分多く笑う |
| 道学者面 | 口では「礼に外れる」と言い、目は一寸も動かない。あとで自分に言い訳を用意する |
| 権を持つ者 | 当然のものとして受け取り、その場で条件を出す（何匹・どの席・何日にどこへ） |
| 粗い者（兵・卒・匪・獄吏） | 回り道をしない。すぐ手が出るか、すぐ口に出る |

**動じない男を書くなら、動じない理由をその場に書くこと**——宦官である／もっと大きな恐怖がある／
今まさに誰かに見られている／その女に具体的な恨みがある。
**理由が書けないなら、それは動じている。**

力の強い種族（ウマ娘など）が相手なら、男は怯えてよい。ただし怯える対象を間違えないこと——
**怖いのは彼女の腕力・腰の牌・背後の千戸であって、近づかれたことではない。**
硬い口をききながら目は逸らさず、心の中では「これ以上言うと蹴られるか」を計算している。三つ同時に書く。

### 14-3. 醜・臭は裏返し（片側だけ書くと嘘になる）

容姿下等、または汗・病・膿の匂いのする者が近づいたときの反応は、逆向きに固定されている。
**まず一度息を止める → 半歩下がる → 話が短くなる → 目が別の場所を探す → 口実を作って会話を切る。**
男女も身分も問わない。これを抑えられるのは身分差だけで、抑えた形は「笑って受け、離れてから罵る」。

醜くて権も無い者が言い寄る・触る・誘惑すれば、返ってくるのは吐き気と怒りであって、心の動きではない。
醜女が匪・兵・獄吏に絡めば、絡まないより結末が悪い。

### 14-4. 権は顔に勝つ

醜くて権のある者が近づけば、絶世でも吐き気を抑えて愛想笑いをする。笑ってから、背を向けて罵る。
美しくて権の無い者が近づけば、返ってくるのは「口数が増える・顔つきが緩む・話に乗る」であって、服従ではない。

だから一幕を組むときは、**まず誰が誰の生死・口分・去就を決められるかを並べ、それから誰が美しいかを並べる。**
二つが衝突したら常に権が勝つ——**口の上では勝つ。心の中では勝つとは限らない。この二層を分けて書く。**

### 14-5. 一人に何本もの声（→ `C26`）

同じ人物でも相手ごとに喋り方が違う。

| 相手 | 声 |
|---|---|
| 上役 | 短文・敬称・先に数字を報告・目線は相手の膝（靴） |
| 同族（猫娘→猫娘、ウマ娘→ウマ娘） | 敬語なし・密度が高い・半句で通じる |
| 下の者 | 名を呼ばない・蔑称・一文に命令が入る |
| 見目の良い若者 | 口数が増え、文が長くなり、冗談を言う |
| 使える相手 | まず褒めてから要求する |
| 使えない相手 | 三言で終わる |

**書くときの検査**——同じ一幕でその人物が二人以上に話しているなら、
**文の長さ・呼称・敬語の有無が二か所で違っていなければならない。同じなら書いていない。**

**自動採点（`C26`）が見るのはその粗い版だけ**である。敬う語と見下す語が**どちらも無い**とき、
つまり一部屋まるごと同じ丁寧さで喋っているときに落ちる。
片側しか無くてもよい——語り手が階層の頂点にいる局（大汗の視点）や、
上位者がその場にいない局（逃亡奴隷・屍を担ぐ少年）に敬語が無いのは正しい。
**「上向きの語が必ず要る」と書いてはならない。それはカード固有の語を式に焼き込むことになる（訂正履歴14）。**

### 14-6. 口と心はずれている（→ 十節・◈心声）

口を開く NPC は全員、**心の一行と口の一行が最低一か所ずれている**。
ずれの種類は六つ——**値踏み／嫌悪／色気／恐れ／見下し／算盤**。

- 清高な人物の心が下品でよい
- 卑猥に見える人物の心が清潔でよい
- 絶世の美女の心が汚くてよい
- 罵られている最中の人物が「この一件は何銭になるか」を数えていてよい

**全員が言行一致・全員が自尊自愛・全員が分をわきまえている一幕は、
一部屋まるごと道徳的模範を並べたということである。書き直す。**

### 14-7. 美貌には二つの面がある（両方書く）

| 面 | 内容 |
|---|---|
| 順 | 門が開きやすい・値が下げやすい・要求が通りやすい・見知らぬ男が話しかけ、手伝い、値を引く。周りが半歩よけてくれる |
| 険 | 匪・兵・獄吏・護送吏の手に落ちたとき、**美しいほど危ない**。城が落ちれば選り分けられるのは美しい側 |

**美人が匪を誘惑すれば、匪は乗る。「侮辱された」と怒る匪はこの世界に存在しない。**
そして**手に入れた＝安全になった、ではない**。一つの事態を別の事態に取り替えただけである。

### 14-8. 禁止（→ `S2g` / `C26`）

出たら書き損じ。

- 美人に近づかれた男が**怯える・逃げる・侮辱されたと感じる**
- 男女・種族を問わず全員が同じ慎み深さと分別で喋る
- 下品な男が一人もいない。卑劣な女も一人もいない。全員の内心が公文のように清潔
- 逆も禁止——**女を見た男が全員色気だけになる／美しい者が必ず得をする**

書くべきは**差そのもの**である。
同じ一言を、違う人間が、違う相手に言えば、返ってくる音は必ず違う。

### 14-9. 状態欄の「眼色」（→ `C27`）

`<sec_npc>` を持つカードでは、◈ 行の**最後の一欄を「眼色」にする**——
**その人物が今この瞬間、目の前の主人公をどう見ているか**を一行（三十字以内）で書く。

- 七項目のうち**最低一つ**に当てる（身分／容姿／匂い／年齢／同類か／使えるか）
- そこから出る態度まで書く（喋る量・先に頭を下げるか・距離・目を合わせられるか）
- **心声の言い換えにしない。道徳評語にしない。同じ幕で数人の眼色を同じ形にしない**

眼色は飾りではない。**値踏みを毎ターン書き出させるための欄**である。
書けないなら値踏みをしていない。

ただし**毎ターン書き出すこと**と**毎ターンゼロから見積もり直すこと**は別である。
同じ相手が何度も出てくるなら、眼色は回を追って動かなければならない（**十五節**）。
二十ターン目の眼色が一ターン目と同じ文なら、それは値踏みを写経しているだけである。

## 十五. 関係には時間軸がある（**十四節の値踏みは、初対面と単発の場面にだけ掛かる**）

十四節で全員に値踏みをさせた。それでもう一つ穴が残った——**その値踏みに記憶が無い**。

同じ相手と何度も会う長い局（パネルを持つカード、続きもののセッション）で、
毎ターンゼロから見積もり直すと、好意をいくら積んでも内心が一行も動かない。
百回目の親切をまだ「裏がある」と読む語り手は、警戒心が強いのではなく**壊れている**。
一篇の開局にはこの節は要らない。**関係史が生まれた時点から掛かる。**

### 15-1. 警戒は回数で落ちる（人柄の判定ではない）

相手を良い人だと**信じる必要はない**。同じ型が変わらずに繰り返されたことを**見た**だけでよい。

| 回数 | 内心の書き方 |
|---|---|
| 1 回目 | 全部裏があると読む。何が欲しいのかを丸ごと計算する。**これは正しい。そのまま書く** |
| 2〜3 回目 | まだ鉤を探している。しかし見つからない。**「裏が読めない」と書く。「裏があると分かった」と書いてはいけない** |
| 4〜6 回目 | 一回ごとの詮索をやめ、まず受け取る。「何が狙いか」から「とりあえず貰っておく、後で数える」へ |
| 7 回目以降 | この件はもう帳面に付けない。同種の好意が来ても、内心は動機に一切触れず別のことを書いてよい |

**硬規則**：同一の関係の中で「弄ばれている／試されている」という読みは**通算二回まで**。
三回目は必ず別の読みに替える——読めない／諦めた／自分が考えすぎかと自問する、のどれか。
最後まで同じ読みを通したら、それは人物ではなく被害妄想である。書き直す。

### 15-2. 変わるのは罵倒の量ではなく、矢印の向き

関係が温まっても **C20（罵倒8個以上）・C22（悔い・良心語ゼロ）・C23・C25 の下限は一切下がらない。**
下がるものは何も無い。**向き先だけが変わる。**

- 冷えているとき：矢印は目の前の相手に向く
- 温まったとき：矢印は**その相手の前に立ちふさがる第三者**に向く

口の悪さが消えたら、それは関係が深まったのではなく**十二節に違反した**のである。
高い好意を「優しい・従順・献身的・しおらしい」と書いた時点で現代の恋人に落ちている。
十四-6 の心口のずれも生きたままである。ただし**ずれの向きが裏返る**——
以前は「口は恭しく、心は刻薄」、いまは「口は刻薄、心は庇っている」。

### 15-3. 緩みは口より先に身体へ出る

先に緩むのは態度ではなく**身体**である。口は最後まで硬いままでよい。

- 耳がもう戸口の方を向かない／尾を低く畳まなくなる
- 背中を向けて座れる／目の前で居眠りできる／半歩近くに立つ
- 手が先に出る（相手が差し出したものを、考える前に受け取っている）

**この二層を同じ一幕の中で同時に書く。**身体は緩み、口はまだ刻薄——その落差自体が芝居である。
身体を飛ばして口が先に柔らかくなったら、それは書き損じ。

### 15-4. 逆側はもっと速い

**一度の不一致は三度の好意を打ち消す。**

- 約束したのに渡さない／人前で顔を潰す／一度与えたものを取り上げる
- **「今まで通り」を突然やめる**——これも不一致である。しかも**これが一番速く戻る**。
  一度も貰ったことがない状態より、貰い慣れてから断たれた状態のほうが警戒は強い

### 15-5. 警戒が落ちても頭は悪くならない

数え続ける人物は数え続ける。値段も付ける。恨みも覚えている。
変わったのは**この一件をもう計算に掛けない**ことだけである。
警戒の低下を判断力の低下として書いたら、それは別の失敗である。

### 15-6. なぜ `measure.py` に検査を足さないか

この節は**一篇の中では測れない**。関係史は篇をまたいで初めて存在する。
参照コーパス7本はどれも単篇の抜粋であり、関係史を持たない——
そこへ「関係変化」の検査を掛ければ7本とも落ちる。
**コーパスが落ちる変更は間違い**（訂正履歴 #13）。よってこの節は散文規則のままにする。
検証は自動採点ではなく、**同じ相手との二十ターン目の内心を一ターン目と並べて読む**ことで行う。
二つが同じ文だったら直っていない。

## 十六. 汚れ方は人によって違う（**総量は落とさない。配り方を変える**）

十一節で口を汚くした。十四節で相手ごとに態度を変えさせた。それでもう一つ穴が残った——
**登場人物全員が同じ汚れ方をする。**

`C20` `C21` `C23` `C24` `C25` はどれも**一篇の合計**しか数えない。
合計を満たす最短経路は「全員に均等に汚く喋らせる」である。
そうすると門番の小卒も、宦官も、女医も、皇帝も、同じ語彙で罵り、
同じ勘定単位で損得を計算し、同じ調子で内心をこぼす。
**声が一本しかない一幕**は、文体が汚いかどうか以前に書き損じである。

**総量は一切落とさない。**下げるのは一人あたりの取り分だけ。

### 16-1. 口に出して罵る人物は、一幕に多くて三人

残りは罵らない。罵らない代わりに、**別の汚れ方**で書く。四つある。

| 型 | 誰が | 書き方 |
|---|---|---|
| **刻薄だが汚くない** | 博士・女医・文吏・貴人 | 語は綺麗なまま。刃は文の組み立てのほうに入れる。「〜とお見受けします」で人を殺す |
| **恭順の下の算盤** | 宦官・下級役人・取次 | 口は敬語で埋まっている。心声は「次に飛ぶのは誰か」「この一件は何銭になるか」しかない |
| **身体だけ** | 兵卒・力役・下働き | 心声にほとんど判断が無い。寒い・腹が減った・足が痛い・これは持ち帰れるか、それだけ |
| **沈黙** | 怯えている者・慣れきった者 | 心声は一行、しかも同じ一句の反復。場面が変わっても同じことしか考えていない |

上位者は人前で下位者を罵る。下位者は人前では罵れない——心の中だけで罵るか、罵りさえしない。
**誰が罵れるかは身分と場面で決まる。**全員が全員に向かって罵れる一幕は、身分の無い世界である。

### 16-2. 最も効く一条：心声の語彙は職掌から出る

その人物が**一日じゅう何を数えているか**で、内心の単位が決まる。

| 職掌 | 内心に出る単位 |
|---|---|
| 門卒・当直 | 班次、腰牌、当直は何時まで、足が冷える、交代は来たか |
| 女医・薬 | 分量、何分何銭、脈、簿は一日二度、前任はどう書いていたか |
| 書吏 | 字数、行数、封泥、この一筆は誰が署名したか |
| 兵卒 | 干し飯、履、今日何里歩いたか、分捕り品は誰のものになるか |
| 宦官・取次 | 誰の門か、昨日誰が入れ替わったか、この話は伝えてよいか |
| 厨・倉 | 斤量、鍵、いくら足りないか、誰が自腹で埋めるか |

**同じ一幕の中で、二人が同じ勘定単位で考えていたら書き損じ。**
これを守るだけで、罵倒を一語も減らさずに声が分かれる。

### 16-3. 罵語そのものを配り分ける

- **同じ罵語を同じ幕で二人に使わせない。**一人が「狗东西」を使ったら、次の者は別の語を使う
- 罵り方の質も分ける——大声で長い者、短く一語だけの者、罵らずに鼻で笑う者、口を動かさず唾を吐く者
- 育ちで語彙が違う。軍のことば・宮のことば・市井のことば・田舎のことばは別の語彙である。
  どこで育ったかで、その人物が持っている罵語の在庫が決まる

### 16-4. 落差の向きも人によって違う（十四-6 の拡張）

十四-6 は「口と心が最低一か所ずれている」と定めた。**そのずれの向きを人ごとに変える。**

- 口が汚くて心が細かい者
- 口が綺麗で心が毒な者

**一幕にこの二種を最低一人ずつ置く。**全員が同じ向きにずれていたら、それはずれではなく様式である。

### 16-5. 自己点検

書き終えたら、◈行の心声だけを縦に並べて読む。

1. **名前を隠しても誰の行か分かるか。**分からなければ書き直し
2. **二人が同じ勘定単位を使っていないか**（16-2）
3. **同じ罵語が二人に出ていないか**（16-3）
4. **口が綺麗で心が毒な者が一人はいるか**（16-4）

自動採点は `C28` がこの1番だけを粗く見る（→ 十六-6）。残り三つは目で見るしかない。

### 16-6. `C28` について

`<sec_npc>` を持つ原稿でのみ働く。◈行の心声を二人ずつ突き合わせ、
漢字二字組の重なり率を測り、最大値が閾値を超えたら落とす。
閾値は手書き44篇（luzhi 24・mongol 20）の実測から引いた——
最大重複の中位 0.067、九分位 0.147、最悪 0.222。**0.35 を境にする。**
参照コーパス7本は ◈行を持たないので、この検査は静かに飛ぶ（訂正履歴 #13 の教訓）。

## 十七. 罵倒の「質」——市場の喧嘩と、精神病質の独語は別物

依頼者の指摘（六度目）：原形が出た瞬間、人物が全員「中国の農村の泼妇が街で喧嘩している」ようになる。
韓国語の罵倒語をいくら入れても出てくるのは泼妇骂街で、欲しいのは**精神病質の内心の罵倒**である。

原因は十一節にある。あそこは罵倒の**量**（`C20`）と**語彙**だけを決め、**語用論**を一行も決めなかった。
量のノルマ＋汎用の罵り語＋「感嘆符を省くな」——この三つが揃えば着地点は一つしかない。

**罵倒の総量は落とさない。**決めるのは「誰に向かって、何のために、どういう温度で」である。

### 17-1. 六つの軸（一つでも左に落ちたらその段落は泼妇）

| | 泼妇骂街（禁止） | 精神病質の罵倒（要求） |
|---|---|---|
| 観客 | 要る。周りに聞かせ、理を認めさせる | 要らない。むしろ見られたくない。心の中か、二人きりの時 |
| 底の感情 | 委屈。「私は被害者だ」 | 優越と退屈。「お前は何様のつもりだ」 |
| 内容 | 既製の呪い（祖先・生殖器・絶家・全家死ね） | この一人にしか当たらない具体的な観察 |
| 音量 | 上がる。繰り返す。伸ばす | 下がる。短い。一度で切る |
| 求めるもの | 賠償・謝罪・仲裁 | 相手の顔が崩れるその一瞬 |
| 終わり方 | 泣く | 笑う。しかも笑う場所がおかしい |

一言でいえば——**泼妇は弱者の公開演説、精神病質は強者の私的な採点**である。
前者は理を認めてほしい。後者は理など要らない。要るのは相手の顔が崩れる一瞬だけ。

### 17-2. 作法

- **既製の呪いは一篇に最大一つ。**「断子绝孙」「不得好死」「挨千刀」「天打雷劈」「死全家」の類は
  それ自体が泼妇の指紋である（`S4`）。姿態も同じ——「叉腰」「捶胸」「顿足」「一屁股坐在地上」「唾沫星子」
- **代わりに名指しの侮辱を一篇に三つ以上。**相手の身体の一点・匂い・持ち物・癖・数字を指す：
  - ×「你他妈的给我滚」——誰に言っても成立する＝誰にも刺さらない
  - ○「你左边那颗牙是黑的。刚才你说话，我一直在看它。」
- **敬語と罵倒を同じ息で吐く。**これが韓国ラノベの核心の落差：
  「请君慢走。」（这狗东西的鞋跟只磨了一边，走起来像条瘸狗。）
- **音量で押さない。**叫ぶのは一幕に一度まで。あとは平叙で。
  感嘆符の総数は据え置いてよい（実測：原典の中位 60/万字、最大 252）。
  問題は数ではなく**同じ罵り文句の繰り返し**——同じ文句が二度出たらその時点で泼妇
- **理を求めない。**「讲不讲理」「评评理」「有没有天理」「我招谁惹谁了」——
  理を求めた瞬間、その人物は被害者になる。
  ただし**「凭什么」は禁じない**：実測でコーパス7本中2本・手書き開局8篇が使っている。
  あれは訴えではなく**勘定**である（「凭什么她三千匹我一匹」＝計算であって嘆願ではない）
- **泣かない。**罵ったあとに泣く／自分の不遇を数える／「我容易吗」は禁止。
  罵ったあとは笑うか、何事もなかったように次の用件へ移る
- **心の中の罵倒は独語であって演説ではない。**一文が短い。突然具体的な数字や物に飛ぶ。
  途中で敬語に戻り、また汚くなる。段落として整っていたらそれは演説であり、聞かせる相手を想定している

### 17-3. 自己診断

罵倒の段落を一つ取り、四つ問う。一つでも「はい」なら書き直し：

1. **周りに人がいなければ成立しないか**（＝観客に向けている）
2. **同じ罵り文句が二度出てくるか**（＝音量で押している）
3. **相手が誰でも成立するか**（＝名指しの具体が無い）
4. **最後が自分の不遇の話になっているか**（＝被害者に落ちた）

### 17-4. `S4` について

`S4` は 17-2 の第一項だけを機械で見る。閾値は勘で作っていない——
候補44語を参照コーパス7本＋手書き開局75篇＋四本の世界書（計75万字）に当て、
**零命中だった41語だけ**を禁止に入れた。実際に使われていた3語
（不得好死・捶胸・坐在地上哭）は落とした。
残りの五項目は機械では見えない。目で見るしかない。
